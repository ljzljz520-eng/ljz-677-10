# 财政补贴名单导入平台

乡镇经办人导入补贴对象名单，系统完成格式与重复校验后分批上送财政平台，
平台退回的异常记录自动生成错误清单，供更正后重新导入。
不同乡镇账号数据完全隔离，只能查看本乡镇的导入任务。

## 功能一览

| 功能 | 说明 |
|------|------|
| 账号登录 | 乡镇经办人账号 + 县财政局管理员账号，密码 PBKDF2 加盐存储，会话 HMAC 签名 Cookie |
| 名单导入 | 上传 CSV（UTF-8/GBK，≤5MB，≤5000行），自动识别表头别名 |
| 格式校验 | 身份证（18位/出生日期/GB11643 校验码）、银行卡（13-19位/Luhn）、金额（>0、两位小数、≤5万元）、姓名、乡镇归属 |
| 重复校验 | 文件内同身份证查重；与本乡镇历史“待上送/已上送”记录查重（平台退回记录不计入，可更正后重新导入） |
| 分批上送 | 校验通过的记录按 20 条/批（`services.BATCH_SIZE`）上送财政平台，逐批记录结果 |
| 错误清单 | 平台退回记录汇总展示，可下载 CSV（带 BOM，Excel 可直接打开） |
| 数据隔离 | 乡镇账号仅见本乡镇任务/明细/错误清单；越权访问返回 404；管理员可见全部 |

## 快速开始

```bash
python3 app.py            # 首次启动自动建库并写入初始账号
# 访问 http://127.0.0.1:8000
```

初始账号（密码建议生产环境通过环境变量或首次登录修改流程下发）：

| 账号 | 密码 | 角色 |
|------|------|------|
| `chengdong` | `Town@2026` | 城东镇经办人 |
| `chengxi` | `Town@2026` | 城西镇经办人 |
| `hekou` | `Town@2026` | 河口乡经办人 |
| `admin` | `Admin@2026` | 县财政局管理员（只读监管，不可导入） |

演示流程：

```bash
# 1. 用 chengdong 登录；2. “导入名单”选择 sample_data.csv（51行：42合法/7格式错误/2重复）
# 3. 任务详情点击“开始分批上送”（42条分3批：20+20+2）
# 4. 查看批次结果与“错误清单”（8条被平台退回），下载 CSV
# 5. 换 chengxi 登录：看不到城东镇的任务（数据隔离）
```

环境变量：`PORT`（默认 8000）、`SUBSIDY_DB`（数据库路径）、`SUBSIDY_SECRET`（会话签名密钥，生产必配）。

## 导入文件格式

CSV 五列（表头支持常见别名，见 `services.HEADER_ALIASES`）：

```csv
补贴对象,身份证号,银行卡号,金额,乡镇
张三,341322199603029991,6222020656601306,1500.00,城东镇
```

- `乡镇` 必须与当前登录账号所属乡镇一致，否则整行判无效；
- 金额单位为元，最多两位小数，单笔 ≤ 50000 元；
- 平台单笔限额 20000 元（`fiscal_client.PLATFORM_LIMIT_CENTS`），超过会被平台退回。

## 财政平台对接

`subsidy/fiscal_client.py` 为模拟客户端，用确定性规则模拟平台返回
（卡号尾 00→已销户、尾 99→已冻结、超 2 万→超限额、姓名含“测”→户名不符）。
接入真实平台时，仅需将 `submit_batch(batch_no, records)` 替换为实际接口调用
（加签/加密/重试），上层分批、落库、错误清单逻辑无需改动。

## 目录结构

```
app.py                 入口与路由（登录、上传、上送、错误清单、模板下载）
subsidy/
  web.py               极简 WSGI 框架（路由、multipart 解析、签名会话）
  db.py                SQLite 建表与初始账号
  validators.py        身份证/银行卡/金额/姓名校验
  services.py          导入解析、查重、分批上送、权限查询
  fiscal_client.py     模拟财政平台客户端（替换点）
  views.py             页面渲染（全部转义防 XSS，列表脱敏展示）
scripts/gen_sample.py  生成演示数据 sample_data.csv 与 template.csv
tests/test_all.py      13 个单元/集成测试（python3 tests/test_all.py）
```

## 安全与生产化说明

- 列表页身份证/银行卡脱敏展示；错误清单含完整号码，仅供经办人更正使用；
- 生产环境需补充：HTTPS、CSRF Token、登录失败锁定、操作审计日志、
  上送异步化（队列+worker）、数据库迁移为 MySQL/PostgreSQL、会话密钥 KMS 托管。
